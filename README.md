# Next Fullstack Forge

**Next.js를 중심으로 프론트엔드부터 백엔드, 데이터베이스, AWS까지 하나의
웹 서비스를 직접 설계·구현·검증하는 풀스택 수련 프로젝트입니다.**

이 프로젝트의 목적은 단순히 기능을 많이 구현하거나 포트폴리오를 빠르게
완성하는 것이 아닙니다. 웹 서비스의 전체 구조와 데이터 흐름을 이해하고,
핵심 코드를 직접 작성하며, 구현 결과를 테스트하고 오류를 추적·수정할 수
있는 개발 역량을 기르는 것입니다.

> **핵심 목표:** 내가 무엇을 만들었는지 이해하고, 왜 그렇게 만들었는지
> 설명하며, 결과를 스스로 검증할 수 있는 개발자가 된다.

## 프로젝트 목표

-   Next.js를 중심으로 프론트엔드와 백엔드가 연결되는 과정을 이해한다.
-   데이터베이스 설계부터 SQL, API 구현, 화면 연동까지 직접 경험한다.
-   기존 라이브러리와 클라우드 서비스를 적절히 활용하고, 각 요소의
    역할과 한계를 이해한다.
-   정상적인 상황뿐 아니라 잘못된 입력과 오류 상황도 직접 테스트한다.
-   AI를 생산성 도구로 활용하되, AI가 작성한 코드도 읽고 검증할 수
    있도록 한다.
-   요구사항이나 조건이 바뀌었을 때 기존 코드를 이해하고 수정할 수
    있는지 확인한다.

## 학습 원칙

1.  **이해한 뒤 구현한다.** 새로운 개념이나 도구를 사용할 때는 역할,
    목적, 시스템 내 위치를 먼저 파악한다.
2.  **직접 생각하고 작성한다.** 핵심 설계와 구현은 먼저 스스로 시도하고,
    막힌 부분은 질문과 힌트를 활용해 해결한다.
3.  **실행 결과를 검증한다.** 코드를 작성하는 데서 끝내지 않고 테스트와
    실제 실행으로 동작을 확인한다.
4.  **오류를 분석한다.** 오류가 발생하면 원인을 추적하고, 해결 방법과 그
    이유를 설명한다.
5.  **AI의 결과를 그대로 채택하지 않는다.** 생성된 코드의 핵심 동작을
    이해하고, 필요하면 수정하거나 대안을 비교한다.
6.  **기능 수보다 습득한 역량을 우선한다.** 프로젝트 완성 자체가 아니라
    독립적으로 설계·구현·검증할 수 있는지를 기준으로 삼는다.

## 주요 학습 범위

프로젝트 요구사항과 학습 진행 상황에 따라 아래 기술을 단계적으로
적용합니다. 모든 기술을 한꺼번에 구현하지 않으며, 실제 기능에 필요한
순서로 통합합니다.

### 프론트엔드

-   React 컴포넌트와 Props
-   상태 관리와 사용자 입력 처리
-   API 요청 및 응답 처리
-   로딩, 성공, 오류 상태 표현
-   TypeScript를 활용한 타입 설계

### 백엔드 및 데이터베이스

-   Next.js Route Handler
-   요청 데이터 검증과 HTTP 상태 코드
-   오류 처리와 일관된 응답 설계
-   관계형 데이터 모델링 및 SQL
-   CRUD, JOIN, 집계 쿼리
-   데이터 정합성과 필요한 트랜잭션
-   인증 및 인가의 기본 적용

### 파일 및 미디어 처리

-   파일 업로드 흐름
-   Amazon S3 및 presigned URL
-   파일 정보 저장과 조회
-   CloudFront를 통한 파일 전달
-   파일 접근 권한과 실패 상황 처리

### 비동기 통신 및 서비스 통합

-   SSE(Server-Sent Events)를 활용한 실시간 통신
-   비동기 데이터 흐름 이해
-   프론트엔드, API, DB, 외부 서비스 간 통합

### 테스트 및 운영

-   주요 API와 사용자 동작 테스트
-   정상·예외 상황 검증
-   오류 추적 및 디버깅
-   환경 변수와 환경 설정
-   Docker 및 AWS 배포
-   배포된 서비스의 동작 확인

### 추가로 집중할 역량

-   **TypeScript:** 타입을 직접 설계하고 컴파일 오류를 분석하며, 정적
    타입과 런타임 데이터 검증의 차이를 이해합니다.
-   **자동화 테스트:** Vitest와 React Testing Library 등을 활용해 핵심
    로직과 사용자 동작을 검증합니다.

## 구현 및 학습 방식

기능은 다음 과정을 반복하며 추가합니다.

1.  요구사항을 분석한다.
2.  필요한 데이터 구조와 API, 화면 간 흐름을 설계한다.
3.  관련 개념을 학습하고 작은 단위로 직접 구현한다.
4.  실제로 실행하고 테스트한다.
5.  오류 원인을 분석하고 수정한다.
6.  구현 이유와 데이터 흐름을 자신의 말로 설명한다.
7.  조건을 바꾸거나 새로운 요구사항을 추가해 다시 적용한다.

프레임워크와 클라우드 서비스의 내부 구현을 전부 다시 만드는 것이 목표는
아닙니다. 제공되는 기능을 올바르게 활용하되, 해당 기능의 역할과 제약,
전체 시스템에서의 동작 방식, 실패했을 때의 처리 방법을 이해하는 것을
목표로 합니다.

## 완료 기준

다음 항목을 실제 코드와 테스트를 통해 확인합니다.

-   [ ] 전체 아키텍처와 데이터 흐름을 설명할 수 있다.
-   [ ] 핵심 DB 구조와 SQL을 직접 설계·작성할 수 있다.
-   [ ] API 요청부터 DB 처리와 응답까지의 과정을 설명할 수 있다.
-   [ ] React 화면과 API를 연결하고 각 상태를 적절히 처리할 수 있다.
-   [ ] S3, CloudFront, SSE 등 적용한 기술의 역할과 데이터 흐름을 설명할
    수 있다.
-   [ ] 정상 요청과 예외 상황을 테스트하고 결과를 검증할 수 있다.
-   [ ] 오류가 발생했을 때 원인을 추적하고 수정할 수 있다.
-   [ ] AI가 작성한 핵심 코드를 이해하고 검증할 수 있다.
-   [ ] 조건이 달라졌을 때 기존 구현을 스스로 수정할 수 있다.

체크리스트를 모두 읽거나 기능을 한 번 실행했다고 완료로 판단하지
않습니다. 직접 구현하고, 설명하고, 검증할 수 있는지를 기준으로 삼습니다.

## 프로젝트 진행 현황

현재는 프로젝트를 구현하기 전 기초를 정리하고 TypeScript를 복습하는
단계입니다. 구체적인 서비스 요구사항과 기능 범위는 기초 학습 이후
확정하며, 불필요하게 범위를 넓히지 않고 핵심 기능부터 순차적으로
구현합니다.

## 기술 스택

예정 기술 스택입니다. 실제 요구사항과 구현 과정에 따라 조정할 수
있습니다.

-   **Frontend:** React, Next.js, TypeScript
-   **Backend:** Next.js Route Handlers
-   **Database:** 관계형 데이터베이스 및 SQL
-   **File Storage / Delivery:** Amazon S3, presigned URL, CloudFront
-   **Realtime:** Server-Sent Events (SSE)
-   **Testing:** Vitest, React Testing Library 및 필요한 API 테스트 도구
-   **Deployment / Environment:** Docker, AWS 및 환경 변수 관리

## 프로젝트의 최종 지향점

이 저장소는 단순히 완성된 결과물을 보여주기 위한 포트폴리오가 아닙니다.
요구사항 분석부터 설계, 구현, 테스트, 디버깅, 통합까지의 과정을 통해
**웹 서비스를 이해하고 직접 통제할 수 있는 개발 역량**을 기르는
기록입니다.
